# Mohamed Aly Nasef

### Coastal Remote Sensing · Satellite Derived Bathymetry · Geospatial AI

I work at the intersection of **coastal remote sensing, satellite-derived bathymetry, geospatial AI, and scientific software engineering**.

My work focuses on extracting and modelling **shallow-water depth, coastal morphology, and seabed information** from satellite observations and complementary geospatial datasets.

My approach combines:

**Physical understanding + Remote Sensing + Spatial Statistics + Machine Learning**

rather than treating ML as a black box.
